Задача 1 доработана с учётом требований задачи 5.

В каталоге istochnick  - файлы источника (на gradio):

Источник направляет на сервер аудио-файл кусками по 1000 байт (черз Web Socket).
Возврат распознаного текста в источник не предсумотрен, т.к. это требование отсутствовало в задаче.
Как и в задче предусмотрена возможность транскрибации как с предварительной очисткой, так и без неё.

В каталоге server размещён собствено оброаботчик на сер вере:

Сервер в асинхронном режиме осуществляет: принятие потока и сохранение в файл, после чего проводит очистку и транскрибацию.
Данный вариант вбран с учётом требования о распознавании аудио-файла и возмжностей модели по оформлению результата.
Принятие звуковые файлы и результат распознавания речи сохраняет в отдельных файлах для каждого обращения к серверу

server/tmp/1

server/tmp/2

server/tmp/3

...

Скрипты тестировалась на одновременном распознавании 6-и звуковых фалов на облачном сервере (8 CPU • 12 ГБ RAM • 100 ГБ NVMe).
